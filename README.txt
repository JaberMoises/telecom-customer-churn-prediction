# Telecom Customer Churn Prediction | Predicción de Cancelación de Clientes

**Machine Learning Project | Proyecto de Machine Learning**

## 🇬🇧 English

### Project Overview

This project focuses on predicting customer churn for a telecommunications company using machine learning techniques. The objective is to identify customers who are likely to discontinue their services and provide insights that can support customer retention strategies.

### Business Objective

Customer churn can negatively affect revenue and long-term business growth. By analyzing customer data and developing predictive models, businesses can better understand churn patterns and prioritize retention initiatives.

### Project Workflow

- **Data Preparation:** Loaded, integrated, and prepared multiple datasets for analysis.
- **Exploratory Data Analysis (EDA):** Investigated data distributions, relationships, and relevant patterns.
- **Data Preprocessing:** Addressed data quality issues and prepared features for machine learning.
- **Model Development:** Trained and evaluated multiple classification algorithms.
- **Hyperparameter Optimization:** Applied model-tuning techniques to improve predictive performance.
- **Model Evaluation:** Compared model performance using appropriate evaluation metrics.

### Models Evaluated

- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting

### Key Results

The selected Gradient Boosting model achieved the following ROC-AUC scores:

- **Test set ROC-AUC:** 0.8445
- **Cross-validation ROC-AUC:** 0.8466

These results indicate that the model can distinguish between customers with different churn outcomes. Further evaluation, including precision, recall, and business costs, would be necessary before deploying the model in a real-world retention strategy.

### Tools and Technologies

- Pandas

- Data Visualization and Exploratory Data Analysis

### Potential Business Applications

- Identify customers who may be at risk of leaving.
- Support data-driven customer retention strategies.
- Help prioritize retention campaigns.
- Provide a foundation for further customer behavior analysis.

## 🇲🇽 Español

### Descripción del Proyecto

Este proyecto se centra en la predicción de cancelación de clientes (*customer churn*) de una empresa de telecomunicaciones mediante técnicas de machine learning. El objetivo es identificar a los clientes que podrían dejar de utilizar los servicios de la empresa y generar información que contribuya al desarrollo de estrategias de retención.

### Objetivo de Negocio

La pérdida de clientes puede afectar negativamente los ingresos y el crecimiento de una empresa. Mediante el análisis de datos y el desarrollo de modelos predictivos, es posible comprender mejor los patrones de cancelación y priorizar las iniciativas de retención.

### Flujo de Trabajo

- **Preparación de datos:** Carga, integración y preparación de múltiples conjuntos de datos.
- **Análisis exploratorio (EDA):** Investigación de distribuciones, relaciones entre variables y patrones relevantes.
- **Preprocesamiento:** Tratamiento de problemas de calidad de datos y preparación de variables para los modelos.
- **Desarrollo de modelos:** Entrenamiento y evaluación de distintos algoritmos de clasificación.
- **Optimización de hiperparámetros:** Ajuste de modelos para mejorar su desempeño predictivo.
- **Evaluación:** Comparación del rendimiento mediante métricas apropiadas.

### Modelos Evaluados

- Regresión Logística
- Árbol de Decisión
- Random Forest
- Gradient Boosting

### Resultados Principales

El modelo seleccionado, Gradient Boosting, obtuvo los siguientes resultados de ROC-AUC:

- **ROC-AUC en el conjunto de prueba:** 0.8445
- **ROC-AUC en validación cruzada:** 0.8466

Estos resultados indican que el modelo tiene capacidad para distinguir entre clientes con diferentes resultados de cancelación. Antes de implementar una estrategia real de retención, sería necesario evaluar también la precisión, el recall y los costos asociados a las decisiones del negocio.
